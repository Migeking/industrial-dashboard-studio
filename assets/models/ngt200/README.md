# SeAH NGT200 参数化三维模型

本模型用于工业大屏数字孪生展示，不是厂家 CAD，也不能用于加工制造或维修拆装。

## 事实依据

用户提供的铭牌信息：

- 产品：空气悬浮鼓风机
- 型号：NGT200
- 吸入风量：83.3 Nm³/min
- 出口压力：75 kPa(g)
- 功率：123 kW
- 电源：380 V / 50 Hz
- 制造日期：2018-10-31
- 制造商：SeAH Engineering Co., Ltd.

厂家产品目录说明 NGT 系列采用空气箔片轴承、高速电机、后弯式叶轮、自冷却系统，并将 PLC、VFD 和本地控制面板集成到隔音机柜。目录中 NGT200 标准外形约为 W 950 × D 2050 × H 1550 mm；现场铭牌数据与目录通用选型范围可能因工况或定制规格不同。

参考资料：

- https://d3pcsg2wjq9izr.cloudfront.net/files/88417/download/667368/SeAHTurboblowerCatalogue.pdf
- https://seahcomp1.cafe24.com/shop2/product/turbo-blower/24

## 模型内容

- 一体式隔音机柜、底座、调平脚和顶部排气消声器
- 本地 HMI、急停按钮、通风百叶与 VFD 舱
- 铝合金蜗壳、出口过渡、进气喇叭口与透明剖切罩体
- 后弯式铝合金叶轮、前后罩盘、曲面叶道、轮毂与导流锥
- 高速电机、主轴，以及含外壳、顶箔、波箔、气膜和轴套层级的进气端/后端空气箔片轴承
- 整机外观、结构剖切与叶轮细节三种视角
- 叶轮动画、旋转观察和缩放

大屏中的 `50 Hz` 来自现场铭牌电源频率；`142 Hz` 和 `284 Hz` 是诊断演示所用的次同步监测峰及二次谐波，不代表厂家额定转频或叶片通过频率。
