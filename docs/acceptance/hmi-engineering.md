# HMI 点表与工程量换算

## 首个验收切片

在 1440×900 浏览器中，从空白工程接入本机 Modbus TCP 测试服务。建立液位、流量和备用液位三个输入寄存器点位，完成试读、批量套用与撤销、画布实时读数和趋势绑定，再发布并读取发布端。

| 点位 | 配置 | 读回 |
| --- | --- | --- |
| LT-101 液位 | 16 位无符号整数，4–20 mA 原码，工程量程 0–6 m | 4000→0 m，12000→3 m，16000→4.5 m，20000→6 m |
| FT-101 流量 | 32 位浮点，上游已换算，单位 m³/h | 18.25 m³/h |
| LT-101 越界 | 原值 3999 | 点表保留原值及无效原因，发布读数取消显示，流量测点继续有效 |

工程量程不合法时提交表单失败，并提示对应点位。发布端趋势使用转换后的液位，显示精度只影响读数格式。`node tests/studio_model_check.mjs` 覆盖旧倍率偏移、旧枚举、两点线性、零值、开关量、坏质量及过期。`python -X utf8 tests/studio_engineering_ui_check.py` 可重跑上述浏览器验收，输出存放于本地 `works/hmi-engineering-acceptance/`。

OPC UA 和 Modbus TCP 共用转换表单。协议扫描设置以 500 ms 为最小值，旧有设置在打开时显示实际使用的扫描下限。点表试读和运行状态可显示桥接最近两次成功采样的间隔。

从演示或 REST 切换至 OPC UA／Modbus TCP 时，原工程位号保留在点表中。选中设备点位，在「关联画面业务位号」选择同类型的原有位号。试读会沿用该位号的工程量程、单位和类型。完成后，已经使用该位号的设备与趋势直接取得新读数，可撤销整次改动。尚未关联的位号显示对应异常原因。历史、告警和其他行数据集可在同一个画面通过「历史与告警接口」接入只读 REST，保留设备协议和原画面绑定。

OPC UA／Modbus TCP 的「超时判定」位于连接设置，适用于整条连接。桥接按该设置检查整批采样时间。桥接仍可访问但设备暂时无新样本时，发布画面撤下过期工程值并显示采样中断，测点诊断保留最后一帧原值。收到新样本后自动恢复。Modbus 台架通过暂停寄存器读取复测此路径，OPC UA 使用同一快照检查。

本机两个独立协议服务分别读取 10 个代表点，包含开关量、液位原码、流量和 CDAB 浮点频率，以及有符号整数。两种协议的读数、质量及 OPC UA 源时间戳通过自动检查。单位换算允许长度、压力、体积及流量的同量纲转换，异量纲配置被拒绝。批量套用前展示逐点差异，可在应用到画布之前撤销整批。

2026-11-19 23:18（北京时间）使用项目采集桥对指定端点执行一次只读测读。OPC UA 的十个标量节点均为有效质量并带源时间戳。Modbus TCP 按北向点表，使用单元号 1、FC02／FC04 读取 4 个 DI 和 6 个 AI，十个原值均返回，七个有效，三个模拟量原值越过固定原码边界。限界诊断保留原值，设备原因需结合站点状态确认。台架换算和现场质量分别记录。
