# HMI 只读值守验证

以预处理进水小工段为独立工程，使用本机只读 REST 台架同时提供当前值、历史行和告警行。07 号经典监视和 25 号工况、趋势及报警显示另有各自的画面回归。

| 数据 | 台架数据约定 | 验证结果 |
| --- | --- | --- |
| 当前值 | `points[]` 的数值点提供值、质量和接收时间 | 液位原码 16000 按 0–6 m 量程换算为 4.50 m |
| 历史 | `points[]` 的行数据集包含时间、数值和逐行质量 | 配置中可选样本字段，乱序样本按实际时间排列，坏质量样本形成断点 |
| 事件 | 行数据包含事件时间、级别、状态和内容 | 时间按实际时刻排序，上游“活动 · 待确认”和“已恢复”都可追溯 |
| 中断和恢复 | 测试源模拟 503 后恢复 | 已发布画面显示离线，已恢复后自动重新显示现值、历史和事件 |
| 发布回退 | 在同一工程发布两版 | 选回旧版并重读发布数据，标题和文档与旧版一致 |

台架通过 `python -X utf8 tests/studio_monitor_trial_check.py` 验证。值守画面和断线截图保存在 `works/hmi-monitor-acceptance/`。本机测试使用 300 ms 刷新设置，单次测得离线识别约 109 ms、恢复约 313 ms。现场周期由站点负载和后续试运行数据确定。

历史和事件可经上游聚合为同一只读快照，表格显示上游返回的行，默认最多八行，可按工程设置调整。确认状态由上游提供。现场试点需明确数据接口及保留时间、工作画面、值守时段和故障演练窗口，再记录 24 小时和 72 小时结果。
