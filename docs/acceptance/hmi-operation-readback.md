# 设备控制面板配置与验证

## 从编辑器配置

1. 放入带运行反馈槽位的泵、风机或其他启停设备。选中设备，打开右侧「交互」，将点击动作设为「打开设备详情」。
2. 在「面板显示」选择画布指标和详情字段。独立设备最多显示一项画布指标，成套图稿最多三项。详情字段可逐项勾选，取消自选可恢复组件默认显示。数据槽位的名称和类型在「元素定义」调整，工程值换算仍在测点映射维护。
3. 在「启停控制」开启设备面板启停。填入两个动作各自的业务命令编号，再从本工程点表选择运行反馈、操作许可和联锁三个独立的开关量。仅配置一个动作时，另一个按钮保持禁用。已绑定的故障反馈无效或有故障时也会禁用启停。
4. 预览或发布后点击设备。明确启用演示的本地 JSON 或 CSV 工程可验证预选、确认、模拟服务回执和模拟设备反馈。当前命令编号只用于标识模拟请求。REST、OPC UA 和 Modbus TCP 工程保持只读。
5. 在「我的图元」保存设备或成套图元并导出。在新工程导入、放置后，画布指标、详情字段、控制槽位和内部管线随模板保存。根据新工程点表重新绑定设备数据，并填写本站命令编号。已放置的实例可继续单独调整。

## 参考做法

- WinCC Unified Faceplate 使用固定接口把面板类型与项目测点连接起来。本平台用数据槽位保留类型和用途，再由实例选点。[WinCC Faceplate 接口](https://docs.tia.siemens.cloud/r/en-us/v20/configuring-screens-rt-unified/configuring-faceplates-rt-unified/editing-faceplates-rt-unified/configuring-tags-in-the-faceplate-type-rt-unified/configuring-interface-tags-in-the-faceplate-type-rt-unified)
- EasyBuilder Pro 对象可分设读写地址，并使用地址标签库管理点名。本平台将动作命令编号、反馈、许可和联锁分开配置。[对象手册](https://dl.weintek.com/public/EBPro/UserManual/eng/UserManual_separate_chapter/Chapter-13-Objects-UserManual-eng.pdf) · [地址标签库](https://dl.weintek.com/public/EBPro/UserManual/eng/UserManual_separate_chapter/Chapter-16-Address-Tag-Library-UserManual-eng.pdf)
- GoView 将图表和页面元素封装为可低代码配置的基础组件。本平台把默认显示和实例的指标、字段选择留在同一套设备上。[GoView 项目说明](https://github.com/dromara/go-view#readme)

## 定义设备按钮弹出的内容

1. 选中设备或普通图元，在「交互」将点击动作设为「打开设备详情」，再启用「使用自定义弹窗」。
2. 设置标题，按需要添加数据字段、开关量按钮和数值设定，可以上移、下移或移除。先在「元素定义」声明槽位，再在「动态与测点」绑定工程点位。
3. 数据字段选显示槽位。动作选择独立的回读、许可和联锁槽位，并填演示命令编号。数值设定还需要配置上下限与步长。预选、确认、模拟回执和有效回读共用现有运行流程。
4. 画布上另放一个导航按钮时，将按钮的点击动作设为「打开设备详情」，并在「弹窗目标」选择已配置的设备。设备和入口按钮一起存成图元后，内部引用随实例重定向，测点和命令编号按工程重绑。

## 把控制面板放到画布

1. 在组件库搜索「控制面板」，拖入画布，选中后点击「配置控制面板」。选「设备操作」时直接选择已经组态的泵或阀门。所选设备的动作、测点、许可、联锁和反馈由弹窗与常驻面板共用。
2. 选「画面交互」时，可依次勾选已配置的数值加减、工况切换和趋势时间切换。可以把面板放到专门的操作画面，选择其他画面的现有控件。各处显示同一项目运行会话中的样本与趋势窗口。
3. 在预览和发布检查中，缺失或已失效的目标会定位到控制面板的「交互」。真实数据连接的设备面板保持只读。本地演示来源可以验证二次确认和独立回读，画面内的趋势切换也可用于只读监视。
4. 把设备与控制面板一起保存为图元时，内部引用随新实例改指新设备。只保存面板时，跨工程放置后重新选择目标。随设备模板导出的控制角色和频率范围继续保留，站点命令编号和测点重新配置。

05 号回流支路用于验证弹窗、画布面板、跨画面回读和跨工程重新绑定。25 号将 PAM 配比、演示工况和趋势档位放进独立的「加药与工况」画面，原工艺画面仍可操作同一批控件。

## 开关阀与变频泵

- 放置开关阀，在「交互 → 阀门开关」启用开关，填开阀和关阀命令编号。在「控制测点」分别绑开到位、关到位、操作许可和联锁。两个到位信号同时有效时显示反馈冲突，两点均为假时显示位置待确认。反馈质量异常、冲突或位置未确认时禁止演示操作。
- 放置变频泵，在「交互 → 变频泵频率设定」开启设定，填命令编号及工程允许的频率上下限和步长。点「应用频率范围」一次保存三个参数。在「控制测点」选独立的 Hz 数值回读，在「动态与测点」绑定实际运行频率。给定值需落在限值和从下限起算的步长网格内。
- 选中泵和阀后保存为「我的图元」。跨工程复用保留内部管线、控制槽位和频率范围。新工程按自己的点表重绑测点并填写命令编号。
- 05 号回流泵站支路验收使用本地模拟点。阀门开到位提供泵的操作许可，阀门关到位提供泵的联锁，泵运行信号提供阀门联锁。到位信号冲突、同时为假或质量无效的演示点均会阻止启泵和操作阀门。泵的实际频率为独立样本，模拟频率设定只更新给定回读。演示范围 28–48 Hz、步长 0.5 Hz 取自本次夹具。

现场启用时，从获准控制服务的命令清单选点，并验收设备身份、允许动作、许可、联锁、回执及机械反馈。

## 05 号停机台架

以 05 号回流泵站的 P-01 为首个本地操作样本。在设备面板点击「停止设备」，核对设备与动作后确认。取消预选时，泵维持原状态。确认后为本次请求生成编号。收到模拟服务回执时仍显示实际运行状态，收到更新且有效的停机反馈后显示完成。操作记录按同一请求编号更新，并保留前值与目标值。

二次确认时重新检查本地演示许可、原绑定与设备反馈。停机请求等待回执期间禁用重复操作。结果超时会显示「结果待确认，请查看最新有效反馈」。状态机要求匹配本次请求的回执，以及回执之后的新鲜停机反馈。旧回执、重复采样和坏质量读数均不能完成请求。
