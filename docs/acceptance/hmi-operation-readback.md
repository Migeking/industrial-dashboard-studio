# 单设备停机操作验证

以 05 号回流泵站的 P-01 为首个本地操作样本。在设备面板点击「停止设备」，核对设备与动作后确认。取消预选时，泵维持原状态。确认后为本次请求生成编号。收到模拟服务回执时仍显示实际运行状态，收到更新且有效的停机反馈后显示完成。操作记录按同一请求编号更新，并保留前值与目标值。

二次确认时重新检查本地演示许可、原绑定与设备反馈。停机请求等待回执期间禁用重复操作。结果超时会显示「结果待确认，请查看最新有效反馈」。状态机要求匹配本次请求的回执，以及回执之后的新鲜停机反馈。旧回执、重复采样和坏质量读数均不能完成请求。

| 检查 | 本地验证 |
| --- | --- |
| 操作员流程 | 在发布画面完成预选、取消、确认、服务接收、独立停机反馈和同一条审计记录。观察浏览器请求，停泵时没有写请求 |
| 基本保护 | 状态机测试覆盖无许可、联锁动作或状态未知、无效反馈、确认过期、错误请求号、拒绝、重复反馈、超时、断线和迟到回执 |
| 读写边界 | 设备模拟器只改变本地演示样本。已连接的 REST、OPC UA 和 Modbus 工程使用只读展示。真实许可、联锁、命令回执和机械反馈须从获准控制服务取得 |

运行 `node tests/studio_equipment_operation_check.mjs` 和 `python -X utf8 tests/studio_v2_check.py`。后一项也覆盖原有现场数据只读回归和离线导出。继续接入真实设备需先完成现场监视试点，并确定设备、动作、控制服务及授权范围。
