# HMI 工艺单元验收

13 号以空白画布重建高密度絮凝沉淀工段。先拖入双加药装置、沉淀单元、潜污泵、过滤器和回流排泥泵，再绑 36 个测点并连接五条管线。

- 两套新图稿由内置 imagegen 生成，图源、生成描述、修订记录、版本和 SHA-256 见[素材清单](../../packages/components/studio/assets/water/provenance.json)。装置图用于画面组态。设备工程图与施工管口尺寸由项目另行提供。
- PAC 和 PAM 各有专用出入口。混接在命令预演和文档校验中会显示介质不匹配。画面连接使用独立颜色，自动走线绕开新设备单元的读数区。
- 运行详情按快混、絮凝和回流排泥展示。PAC、PAM 两路计量和两台搅拌机使用各自测点，整机状态依旧由整机反馈决定。
- 已在 1920×1080 发布和 1366×768 离线画面检查相同图稿和管网。通过实际拖入、端口连接、缩放及发布验证。离线文件收录画面实际引用的设备图，浏览器读取离线文件时无需 HTTP。
- 三份[可导入图元](../../apps/scada-designer/examples/units/)在独立空白工程试放。05 为回流泵阀组，13 为高密度沉淀与双加药，25 为双线污泥脱水。保留内部管道及槽位，重新选择目标工程测点。

放置成套图元后，选中组合并打开「组合测点绑定」。在同一个窗口中切换设备或管线，按名称或业务编号搜索目标工程测点。窗口只显示槽位允许的数据类型，并汇总必绑缺项。应用时整批写入草稿，一次撤销可恢复整批。13 号在新工程读入一套不同编号的 36 个演示测点，完成取消、整批应用、撤销、重做和发布，原图稿及内部管线逐项核对一致。

在「我的图元」可用画布选中内容更新，也可从现有图元卡片选择修订文件。确认前可看到元素与管道数量、接口方向和介质、接口位置以及测点类型和必绑状态的变化。已有文件按修订 1 读取，导出文件携带当前修订号。确认或撤销只影响项目图元库，已放置实例沿用各自的管线和点位。

13 号跨工程复用测试导入了一个 PAC 进口位置调整、增加必绑出水浊度的修订文件。浏览器覆盖更新预览、取消、确认、撤销和重做。再次放置时生成了采用新接口和槽位的独立实例，旧实例的图元与管线逐项一致。

复用后的成套设备改宽或改高时，沿用默认图稿锚点的管口会重新贴到图稿上。手动修改过坐标的管口按用户设置的宽高百分比定位。13 号回归分别改变宽度和高度，核对五个管线端点与图稿锚点，以及撤销恢复。原工程还核对了编辑、发布和横屏离线三处的端点位置。

运行 `python -X utf8 tests/studio_scene13_units_ui_check.py` 可生成画布、发布、详情和横屏离线截图以及结果清单。证据保存在本地 `works/scene13-assembly-acceptance/`。另复测了 05 号泵阀复用和 25 号工况、趋势、故障与离线交互。
