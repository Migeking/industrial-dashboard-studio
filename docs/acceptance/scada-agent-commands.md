# 辅助设计 A1 / A2：命令执行与原画布预演

实现位于 `codex/visual-config-platform`，使用既有 Vue / X6 / screen-document。此阶段交付确定性的工程任务回放和可供模型调用的命令函数；尚未接入语言模型，也没有新增现场操作能力。

## 使用流程

本机编辑器 `http://127.0.0.1:8137` 已准备好一张真正空白的画布和 33 个内嵌模拟测点；已发布结果可在 `http://127.0.0.1:8137/view` 查看。8136 的原 2.5D 演示独立保留。

1. 当前界面点顶部“AI 画图”，展开“固定泵站任务（无需模型）”，选择两台、三台或四台并联泵。本文记录固定任务，新增对话入口见 [A3 验收](scada-agent-model.md)。
2. 点“使用当前点表”允许本批在已有点表内推荐测点，再点“生成泵站预演”。不选择点表也能先画设备和管道，槽位会显示待绑定。
3. 在同一画布看设备和管网，金色提示标明本批涉及的对象。逐槽检查推荐测点，可改为同类型的其他点或“稍后绑定”；下拉框显示业务编号、单位和当前质量。草稿尚未改变，保存及发布按钮在预演期间停用。
4. “取消预演”恢复原画布；“确认应用到画布”一次替换草稿，之后可正常手工拖动、改属性、保存。点一次顶部“撤销”或按 Ctrl+Z，整批恢复；“重做”恢复整批。
5. 对已有画面再次生成时，按同名同类型设备和已连接端口复用，保留原几何及绑定，补齐缺失设备和连接。存在多个同名设备时要求先整理名称，避免猜测设备身份。
6. 完成后沿原有“预览发布”检查和发布。待选槽位会进入原发布检查，不被自动忽略。

## 执行器合同

`packages/runtime/studio/screen-commands.mjs` 导出 `screenRevision(project)`、`executeScreenCommands(project, proposal, allowedPoints, makeId?)` 和确定性任务 `pumpStationProposal(project, pageId, pumpCount, allowedPoints)`。

提议为 `{id, pageId, baseRevision, operations}`。修订基于完整保存文档的长度和 64 位内容指纹，实时点值没有进入修订。单用户编辑采用此指纹防止意外覆盖；它不是身份校验或密码学签名。批次 ID 在当前编辑器会话里防止重复应用。应用时再次针对当前文档执行和校验，不直接采用旧的预演副本。

| 命令 | 用途与校验 |
| --- | --- |
| `addNode` | 通用图元、临时 ID、名称、位置、尺寸和有限的量程/单位参数；继承画面主题与绘图外观。位置越界直接拒绝 |
| `moveNode` | 只移动当前页图元，保留绑定和端口；锁定对象不能修改 |
| `setAppearance` | 仅允许该图元声明的内置预设；用户图稿沿原外观面板载入 |
| `addPort` | 增加显式命名的连接点，支持坐标与方向，禁止重复 ID |
| `connect` | 指定双方节点和接口，支持手动转折点；拒绝缺失接口、错误方向、自连同一接口、重复连接及跨页引用 |
| `bindSlot` | 测点必须属于本批允许列表，类型与槽位一致；已有单位冲突拒绝，已有绑定的更换回原属性面板确认。空值保留待选，不伪造点或读数 |

所有操作先在原文档的深副本上执行，最后跑现有 `validateScreen`；任一步失败都不改原文档。输入字段采用白名单，每批最多 300 项，辅助设计当前页最多 500 个图元 / 1000 条管道。函数不访问网络、文件、采集协议或发布接口。开发调试可在助手的折叠区导入同一合同的 JSON 批次，模型接入阶段继续复用此入口。

## 05 空白实测证据

`python -X utf8 tests/studio_agent_ui_check.py` 使用生产编辑器、临时独立项目与本地 HTTP 模拟点表。最初节点和管道均为零，经过数据连接表单读取 33 点，没有导入场景 HTML、图片背景或预制图块。四泵预演由命令放置 18 个图元、20 段管道和 34 处绑定。

| 验收项 | 证据 |
| --- | --- |
| 先画图、后绑点 | 未允许点表时预演显示 34 个待选槽位，确认后所有绑定为空，一次撤销回空白 |
| 预演与取消 | 图元和管道在原画布显示，服务端草稿逐字段不变；取消回零节点 |
| 选点与应用 | 清空并重选 P-04 运行槽位时待选数量随之变化；确认后保存为独立通用图元和连管 |
| 撤销 / 重做 | 一次撤销后工程与原空白工程逐字段相同，一次重做与已应用工程逐字段相同 |
| 补图 | 删除 P-04 及其相邻连管，再生成四泵任务；补回泵、连接与测点，其余节点逐字段不变 |
| 无效批次 | 模型回归覆盖半批失败、越界、错误类型、单位、方向、重复 ID、跨页、锁定对象、未允许点和过期修订；无原文档写入 |
| 发布 / 离线 | 保存重开、原发布流程、液位与流量显示、坏质量停流及恢复、1920×1080 / 1366×768 通过。离线打开 18 节点 / 20 管道，零 HTTP 请求、零页面错误 |

回归入口：`node tests/studio_commands_check.mjs`、`python -X utf8 tests/studio_agent_ui_check.py`、`python -X utf8 tests/studio_depth_ui_check.py`、项目要求的 `validate-dashboard.js scenarios` 和 `interaction_check.py`。本轮结果写入 `works/scada-agent-acceptance/results.json`；截图为 `01-preview.png`、`02-published.png`、`03-published-1366.png`，便携模拟工程和离线页面为 `scene05-agent-project.json` 与 `scene05-agent-offline.html`。

## 实测后优化

预演期间停用保存和发布，避免误把旧草稿当作已生成结果。命令错误保留提议编辑区和错误提示，便于修正重试。点表选择与命令调试分开，普通流程不要求编写 JSON。拉宽设备时，接管短线依据图稿的实际等比尺寸和透明边界计算，消除了图元边界与图稿之间的断管空隙；未改动工艺连接关系。

A3 已增加模型调用路径和对话入口，模拟接口回归通过；真实 13 号模型绘图与人工/模型耗时对照仍未通过，详见 [A3 验收](scada-agent-model.md)。本次软件和模拟实测不替代现场设备验收。
