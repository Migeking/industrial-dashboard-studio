# 05 污泥回流泵站空白画布实测

2026-11-18 在正式二维编辑器中，从新项目空白画布完成 05 的工艺监控重建。通过鼠标和属性表单摆放 31 个对象、绘制 21 段管道、生成 29 个测点并完成 45 处绑定。逐条校验保存后的管道端口，重新打开草稿后发布，并检查独立展示端和离线文件。

数据源使用本机只读模拟 API。正常工况为 P-01、P-02 运行且频率 38.5 Hz，P-03、P-04 停机，液位 3.24 m、设定参考值 3.20 m、出口流量 684 m³/h。数值取原版正常演示画面作比较。液位设定参考值仅用于展示。随后测试故障、有效零值、坏质量和恢复。每条动态管道的流动来自绑定的布尔量，供测试的母管和支路流动信号由模拟源提供。

实测中修复的编辑问题：

1. 小分支的端口彼此靠近，网格吸附可能把管道接到旁边的接口。连管现在以指针命中的端口为准，21 段均核对了保存的起点和终点。
2. 多段管道在图层列表中都显示相同默认名。未自定义名称时显示两端设备或开放端坐标，并按显示名称搜索。
3. 靠拖拽很难对齐出水母管的两个折点。右侧属性可添加、输入或删除折点，非法坐标会保留上次合法值并提示范围。
4. 流动虚线改为叠加在连续底管上，流动颜色独立可配。停止或数据无效时，管网仍清晰可读。
5. 增加通用止回阀图元，具有可编辑的进出连接点。机械止回阀无需配置虚构的开到位读数即可发布。
