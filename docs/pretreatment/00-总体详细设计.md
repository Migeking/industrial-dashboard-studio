# 智能调蓄工程 SCADA 上位系统 — 总体详细设计

> 版本 v2.0 ｜ 2026-09-21 ｜ 数据源：《业务台账_主控版.xlsx》（49 台 / 424 点）
> 配套：《AI脚本控制逻辑梳理.md》T1~T4 模板定义
> **视觉体系（v2.0 变更）**：全站统一采用 `skills/light-3d-water-hmi` 浅色 3D 水务数字孪生风格，废弃深色 SCADA 方案
> 本仓库仅做**上位监视（SCADA/HMI）**，控制逻辑由基站 AI 脚本实施；演示数据使用 demo 适配器，不宣称现场接入。

---

## 1. 项目定位与边界

| 项 | 约定 |
|---|---|
| 架构前提 | 49 台 RVKZBoard 空逻辑，业务逻辑在基站 AI 脚本（Groovy），上位机只读监视 + 报警 + 参数展示 |
| 视觉基调 | 浅灰蓝单主题、白模水工构筑物 3D 主视觉、长期值守低疲劳；禁止霓虹/黑背景/大面积发光渐变 |
| 画布 | 1920×1080 基准，等比缩放（1366/1920/3840），横屏优先 |
| 数据 | `demo` 适配器（固定工况脚本 + 有界周期变化，不用无约束随机数），数据结构预留给 `rest`/`websocket`；每点携带 `quality`/`timestamp` |
| 只读边界 | 18 台"无逻辑"控制器（潜污泵/出口阀/砂水分离器/启闭机/脱水罗茨风机）**只做状态监视**，不演示自动控制，界面标注"手动管理·需求待补齐" |
| 演示诚实性 | 阈值/延时均为示例值（液位差 300mm、循环 10/30min、H₂S 启停值），界面提供参数面板并标注"待工艺标定" |


### 3.2 材质规约（Three.js，本地 `vendor/three*.js` + OrbitControls）
- 混凝土构筑物：偏蓝白，roughness 0.6~0.8，无镜面高光；池体有真实厚度、开口、水面、内壁，可半透明前壁示内部。
- 设备：白体+深蓝部件；工艺管道蓝色（TubeGeometry/圆柱段，转折平滑）；药剂/辅助管道低饱和紫。
- 水面：半透明蓝灰或浅黄褐，不抢构筑物轮廓。
- 阴影柔和偏蓝灰；雾蓝地面+淡蓝网格；禁止霓虹、黑底、营销式玻璃卡。

### 3.4 交互与状态规约（全站强制）
1. 点击 3D 设备（泵/阀/格栅/闸门）→ 右侧面板更新选中对象，不遮挡主模型。
2. 设备状态用真实语义表达：泵组转动、格栅耙齿动作、水流粒子速度映射流量；**停机/关阀时对应动作立即停止**。
3. 质量 `bad/stale` 点：数值显示 `--`，设备标签加琥珀角标；tooltip 说明断线。
4. 手动管理设备：标签加"手动"琥珀角标，控制标签页呈只读说明态。
5. 事件记录：开阀/启停/报警进右栏"事件"标签 + 底部联锁/阀门列。
6. `prefers-reduced-motion` 降级：关闭循环粒子与非必要过渡。
7. 演示模式声明常驻（第二层导航右端或底部），不宣称连接现场 PLC。

## 4. 数据契约（demo 适配器统一结构，与 v1.0 相同）

```js
point = { alias, value, quality: 'good'|'bad'|'stale', ts }
device = { id, name, controller, points: {...}, mode: 'auto'|'manual'|'unknown', state }
scenario = { meta, points: [...], devices: [...], events: [...], params: {...} }
```

- `params`：液位差阈值、循环时间、H₂S 启停值等，可配置并持久化 localStorage。
- 工况脚本覆盖 正常/触发/循环/故障/断线 5 类剧本，可手动注入；固定脚本 + 有界周期变化。

## 5. 交付流程（逐场景串行）与验收

1. 每场景先出本目录 `0N-<场景>详细设计.md`，再实现 HTML。
2. 单场景验收：
   - `node skills/light-3d-water-hmi/scripts/validate-light-3d-hmi.js <file>`
   - `node skills/industrial-dashboard/scripts/validate-dashboard.js <file>`（画布/离线校验）
   - `python -X utf8 tests/interaction_check.py`
3. 1920×1080 / 1366×768 / 3840×2160 三档截图目视检查（第一眼 3D 工艺区 → 右面板 → 底部六联；缩放无文字裁切），留档 `works/`。
4. 全部完成后更新 `apps/showcase/index.html`、README 场景清单、构建 release。
