## 1. 工艺流程与 3D 场景构图

```
进水启闭机(GS-K01-14) → 进水井 → 粗格栅 1~3#(GS-K01-11) → 潜污泵 1~5#(GS-K01-01~05)
                                                      ↓皮带输送机(GS-K01-12)→ 渣外运
                              液位差计 LE11/12/13(GS-K01-16) → T2 联动
                              砂水分离器+补水阀(GS-K01-13) → 出口阀 1~5#(GS-K01-06~10)
```

3D 场景（占宽 72~76%）按水力路径布置白模构筑物群，相机 30~38° 透视、左前上方轴测初始视角，可拖动旋转/滚轮缩放（限制俯仰与距离）：

| 分区 | 白模构筑物 | 占位 | 3D 动效 |
|---|---|---|---|
| A 进水段 | 进水井 + 启闭机闸门（GS-K01-14） | 15% | 闸门开度升降；开度→进水流粒子 |
| B 格栅段 | 格栅渠×3 + 粗格栅机 1~3#（GS-K01-11）+ 皮带输送机（GS-K01-12，渠侧渣线） | 35% | 格栅耙齿往复；皮带滚筒转动；渠内水流粒子 |
| C 泵阀段 | 湿井 + 潜污泵 1~5#（GS-K01-01~05，半透明前壁示泵位）+ 出口阀 1~5#（GS-K01-06~10）+ 出水管 | 35% | 泵组转动 + 频率映射转速；阀体旋转 90° 开关到位；出水管粒子 |
| D 辅助段 | 砂水分离器 + 补水阀 1#/2#（GS-K01-13）+ AE-11a 气体探头测杆（GS-K01-01 扩展） | 15% | 分离器螺旋微动；测杆呼吸灯仅报警时 |

管路着色：进水/出水工艺管蓝色，补水/药剂管低饱和紫；流动粒子沿 TubeGeometry 管线移动，受阀位/泵状态控制，停机即停。楼梯、栏杆、支架、测杆建立工程尺度。

## 3. T2 格栅联动演示逻辑（demo 剧本核心）

按梳理 §3-T2 实现**可视化演示**（非真实控制）：
1. ΔL_max ≥ 300mm（可设）→ 3 台格栅状态块转"运行"，皮带**先于格栅 2s 启动**（启动顺序演示：先皮带后格栅）；回落 + 迟滞 45s → 同步停止（先格栅后皮带）。
2. 时间循环模式：运行 10min / 停止 30min（可设），与液位差"或"触发。
3. 故障联锁：任一设备故障 → 全组立即停机 + 报警 + 循环暂停；复位按钮重新计时。
4. 右栏"T2 联动状态卡"：当前模式（液位差/时间/手动）、ΔL 实时值、倒计时、下次循环时刻。

### demo 剧本（5 类，可手动注入）
| 剧本 | 表现 |
|---|---|
| 正常运行 | ΔL 在 120~260mm 波动，格栅停，泵按液位趋势间歇运行 |
| 液位差触发 | ΔL 缓升至 320mm → T2 联动时序完整播放 |
| 时间循环 | 切换时间模式，倒计时可见 |
| 设备故障 | 注入 2#格栅故障 → 全组停机报警，皮带联锁停 |
| 探头断线 | LE12a/b quality=bad → ΔL 显示 -- + 黄色斜纹，T2 状态"输入无效·暂停" |

## 4. 页面结构（统一骨架见 00 文档 §3.3，浅色 3D 布局）

**第一层顶栏 76px**：`调蓄池 · 格栅预处理`｜工艺模块导航（4 场景）｜演示模式声明｜时钟/用户。
**第二层工段导航 52px**：进水段 / 格栅段 / 泵阀段 / 辅助段 —— 点击聚焦对应 3D 分区（相机平移），当前项实心蓝底。

**主区（65% 高）**：
- 3D 场景 72~76% 宽；左上返回总览缩略图；左下 3×2 核心数据浮层（ΔL_max、进水流量、泵运行台数、格栅状态、皮带状态、报警数）。
- 点击 3D 设备 → 右侧面板更新选中对象；设备标签含名称+控制器编号，质量位异常加琥珀角标。

**右侧控制面板（24~28% 宽）**，横向标签页「状态 / 控制 / 趋势 / 事件」：
- 状态：选中设备全部点位表（别名/值/质量位/时间戳）。
- 控制：T2 联动状态卡（模式、ΔL 实时值、倒计时、下次循环时刻）+ 参数调节（液位差启停值、迟滞、T_run/T_stop、仿真速度，localStorage 持久化，标注"待工艺标定"）。手动管理设备此页呈只读说明态。
- 趋势：ΔL 三组 + 泵频率 ECharts 折线（极淡网格、2px 线、低透明面积）。
- 事件：开阀/启停/报警流水，三态（未确认/确认/清除）。

**底部 25% 连续六列**：液位趋势｜流量趋势｜仪表状态（LE11/12/13 六探头质量位）｜联锁状态（T2 时序）｜阀门状态（启闭机+5 出口阀+2 补水阀）｜设备健康（16 台控制器通信/故障汇总）。不做悬浮卡片瀑布。

**演示模式声明**：第二层导航右端常驻"演示数据 · 非现场接入"。
