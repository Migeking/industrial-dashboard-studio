# 工业精密设计系统

## 视觉目标

界面应呈现稳定、精密、克制和可靠的工业软件气质。装饰不能与状态竞争，正常运行时画面整体保持安静，异常出现时局部状态才能自然突出。

## Token

```css
:root {
  --bg: #071019;
  --surface-1: #0b1622;
  --surface-2: #0f1d2a;
  --surface-3: #132536;
  --line: #20394a;
  --line-strong: #31566d;
  --accent: #36c2ff;
  --accent-soft: rgba(54,194,255,.14);
  --success: #35d07f;
  --warning: #ffb547;
  --danger: #ff5d5d;
  --offline: #708594;
  --text-1: #f2f7fa;
  --text-2: #a8bac8;
  --text-3: #708594;
  --radius: 8px;
  --gap: 14px;
}
```

允许按行业微调 `--accent`，但不得改变状态色含义。安全场景也不能把整屏红色当主题色。

## 字体层级

- 页面标题：34–40px，字重 700。
- KPI：36–52px，必须启用 `font-variant-numeric: tabular-nums`。
- 面板标题：18–20px，字重 650。
- 正文、设备标签：15–16px。
- 图表轴、刻度：13–14px。
- 辅助英文标题不超过中文标题视觉权重的 35%。

## 面板与背景

- 背景可使用极弱拉丝纹理和局部径向光，但禁止大面积高亮光晕。
- 面板使用一级或二级表面色、1px 低对比边框和轻微内高光。
- 圆角统一为 8px，设备卡可用 6px；不使用大圆角 SaaS 卡片风格。
- 阴影只用于区分层级，不使用多重霓虹外发光。
- 铆钉、齿轮、扫描线等装饰最多选择一种，并降低到不影响阅读的透明度。

## 状态规则

| 状态 | 颜色 | 使用范围 |
|---|---|---|
| 正常/运行 | `--success` | 设备状态、达标状态 |
| 预警/关注 | `--warning` | 趋势偏移、维护窗口 |
| 报警/危险 | `--danger` | 超限、故障、联锁动作 |
| 离线/未知 | `--offline` | 通信断开、质量不可信 |
| 选中/主数据 | `--accent` | 主趋势、选中项、流向 |

同一元素不能同时使用主题色和状态色。红色不得用于普通按钮、标题和装饰边框。

## 图表

- 图表背景透明，网格线使用 `rgba(168,186,200,.08)`。
- 坐标轴文字不低于 13px；图例与单位清晰分离。
- 折线默认 2px，重要实时线 3px；面积透明度不高于 `.16`。
- 一张图最多突出两条主序列，其他序列弱化。
- 不使用 3D 饼图、立体柱和无数据意义的雷达图。

## 动效

- 管道流向：1.8–3.2s 线性循环。
- 设备旋转：速度映射到真实工况，停机时暂停。
- 反应釜正视图中的竖轴搅拌器不得按屏幕平面做 360° 风扇旋转；使用以轴心为原点的横向投影变化模拟绕竖轴旋转。只有俯视图叶轮才使用平面旋转，并显式设置 `transform-box` 与 `transform-origin`。
- 未确认高优先级报警可使用 1.2–1.8s 呼吸，不快速闪烁。
- 支持 `prefers-reduced-motion`，关闭循环位移和呼吸。
