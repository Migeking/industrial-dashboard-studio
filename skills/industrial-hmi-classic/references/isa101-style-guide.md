# ISA-101 水务中控工业灰度设计指南 (High-Performance HMI)

## 1. 核心设计哲学

水厂中控室操作员每天需要连续面对监控画面 8~12 小时。传统的深黑色暗黑风格在暗室中有视觉冲击，但在白天明亮的中控室中容易反光，且大面积深色发光会导致视觉边缘疲劳；而传统“花花绿绿”的界面则会让真正的报警信息被淹没。

ISA-101 规范强调**态势感知（Situation Awareness）**：
- **正常即静默**：所有处于正常运行态的设备、池体、管道使用中性低饱和度的工业冷灰；
- **异常才激活**：颜色仅用于吸引注意（如黄色预警、红色危险报警、绿色运行动作）；
- **无眩光无发光**：杜绝 CSS 渐变高光投影、霓虹发光与荧光边框。

## 2. 标准工业灰调色板 (TIA Neutral Palette)

| 元素分类 | 推荐色值 | 视觉用途 | 说明 |
| :--- | :--- | :--- | :--- |
| **画布主背景** | `#DDE2E8` 或 `#E3E8ED` | 整个 SCADA 主视窗背景 | 经典西门子博途 / PCS7 灰蓝底色，抗反射 |
| **工作面板/卡片底色**| `#EDF1F5` / `#FFFFFF` | 参数框、弹窗面板基底 | 形成清晰且温和的视觉层级 |
| **标准边框线** | `#B0BEC5` / `#90A4AE` | 构筑物边界、管道轮廓 | 严谨低饱和冷灰线条 |
| **立体下凹边框** | `2px inset #CFD8DC` | 经典 I/O 域输入数显框 | 西门子经典凹陷物理质感 |
| **文本主色** | `#1C2833` | 位号、工艺名称、数值 | 极高对比度（> 7:1），清晰易辨 |
| **次级说明文本** | `#546E7A` | 变量描述、工程量单位 | 辅助信息，不喧宾夺主 |

## 3. 水厂设备工况状态色

| 设备状态 | 颜色与标记 | 视觉效果 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **正常运行 (Running)** | `#00C853` (纯正运行绿) | 纯色填充或亮绿指示灯 | 潜水泵、鼓风机、加药泵处于运转中 |
| **正常停机 (Stopped)** | `#78909C` (中性暗灰) | 静态中性灰填充 | 备用设备、轮换停运状态，非故障 |
| **报警/故障 (Fault)** | `#D32F2F` (高亮红闪) | 1Hz 频率红白交替闪烁 | 电机过载、热保护动作、水质严重超标 |
| **就地检修 (Local/Lock)**| `#FFA000` (警示黄) | 带锁形或就地挂牌图标 | 现场维护中，严禁中控远程遥控 |
| **通信中断 (Disconn)** | `#9E9E9E` (斜纹占位) | 斜向灰白条纹或打叉 | 远程 PLC/子站通信超时丢失 |
