# 西门子水务标准 Faceplate（操作面板）设计规范

## 1. 结构与层级

西门子博途（TIA Portal WinCC Unified / PCS7）水务标准库中的 Faceplate（画面窗口）遵循经典的物理工业控件设计，由五个标准分区组成：

```
┌───────────────────────────────────────────────────────────┐
│ [FIC-201]  好氧池曝气调节回路                 [？][─][✕]  │ ← 1. 标题区
├───────────────────────────────────────────────────────────┤
│ 状态: [中控远程] [PID自动] [无联锁] [环保达标]            │ ← 2. 状态胶囊灯
├───────────────────────────────────────────────────────────┤
│ 【垂直彩色棒图】            【数值设定与点动微调】        │
│ 5.0 ─┐                     测量值 (PV):  [ 2.38 ] mg/L    │ ← 3. 核心监控与微操区
│ 3.5 ┼─ HH 报警 (红)        目标值 (SP):  [ 2.20 ] mg/L    │
│ 3.0 ┼─ H  预警 (黄)        输出开度(OP): [ 65.0 ] %       │
│     │ █ 当前PV (2.38)                                     │
│ 2.2 ┼─ ◄ SP 指针 (金黄)    模式选择: (•)自动  ( )手动    │
│ 1.5 ┼─ L  预警 (黄)        步进微调: [ -0.1 ] [ +0.1 ]   │
│ 1.0 ┼─ LL 报警 (红)                                       │
│ 0.0 ─┴──────────────────── 控制执行: [ 下发设定值 (SBO) ] │
├───────────────────────────────────────────────────────────┤
│ 标签页: [ 主监控 | PID整定参数 | 报警限值设定 | 联锁逻辑 ]│ ← 4. 功能标签页
└───────────────────────────────────────────────────────────┘
```

## 2. 西门子水务垂直棒图 (Bar Graph) 规范

垂直棒图是上位机中判断工艺量安全裕度最直观的图元：
1. **量程标尺**：必须明确标出最低工程量（0.0）与最高工程量（如 5.0 mg/L）；
2. **四限报警刻度游标**：
   - **HH（高高报）**：红色标线与文字，如 `3.5`；
   - **H（高报）**：黄色标线与文字，如 `3.0`；
   - **L（低报）**：黄色标线与文字，如 `1.5`；
   - **LL（低低报）**：红色标线与文字，如 `1.0`；
3. **PV 柱状高亮填充**：正常范围内为高对比纯绿（`#00C853`）或水务蓝（`#1976D2`），超过 H/HH 或低于 L/LL 时动态变色；
4. **SP 设定值三角游标**：在标尺右侧清晰标注一个**金黄色实心三角指针（`◄`，`#FBC02D`）**，直观展示当前测量值相对目标值的偏差。

## 3. 立体下凹 I/O 域 (Input/Output Field) 规范

- **视觉样式**：
  ```css
  .siemens-io {
    background: #FFFFFF;
    color: #1C2833;
    border: 2px inset #B0BEC5;
    box-shadow: inset 1px 1px 2px rgba(0, 0, 0, 0.15);
    font-family: "Bahnschrift", "Segoe UI", sans-serif;
    font-size: 14px;
    font-weight: 700;
    padding: 3px 6px;
    text-align: right;
  }
  ```
- **点动微调 (Inching Buttons)**：
  - 提供 `[-0.1]` / `[+0.1]` 或 `[-1%]` / `[+1%]` 立体微调轻推按钮，方便操作员细粒度修正；
- **防误操作 (SBO 预选确认)**：
  - 修改设定值并点击下发时，弹出二次模态确认窗，显示原值与新值，经过操作员二次确认后写入 PLC。
