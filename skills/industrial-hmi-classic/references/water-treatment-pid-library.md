# 水务行业标准 P&ID 图元与流体管网色标库

## 1. 城镇水务管道标准色标

按照《城镇污水处理厂在线监控系统技术规范》与工业管路标准识别色（GB 7231）：

1. **原污水 / 进水管 (Sewage)**：
   - 颜色：深灰褐 / 污水灰 `#5D4037`（RGB: 93, 64, 55）
   - 管道粗细：4~6px 实线，正交走线。
2. **生化混合液 / 回流污泥管 (Mixed Liquor / Sludge)**：
   - 颜色：深赭石色 `#4E342E`（RGB: 78, 52, 46）
   - 包含好氧回流（内回流硝化液）与二沉池回流（外回流活性污泥）。
3. **达标出水 / 清水管 (Treated Effluent / Clean Water)**：
   - 颜色：天蓝色 `#1976D2`（RGB: 25, 118, 210）
   - 二沉池出水、紫外消毒出水及回用水。
4. **压缩空气 / 曝气风管 (Aeration Air)**：
   - 颜色：明黄 / 暖黄 `#FBC02D`（RGB: 251, 192, 45）
   - 鼓风机房至好氧池底部微孔曝气盘总管。
5. **碳源药剂投加管 (Chemical Feed - Carbon/Acetate)**：
   - 颜色：紫红虚线 `#8E24AA`（RGB: 142, 36, 170）
   - 线型：`stroke-dasharray="4, 3"`，标示加药微量液体。

## 2. 正交走线与 Jumper 跨线半圆弧

工业 P&ID 严禁任意角度斜线，所有管道拐角必须为严格的 **90° 正交拐角**。

## 3. 水处理专用 P&ID 工业符号图元

### 3.1 水构筑物侧立面与水深标高标尺
- **池体表示**：双层矩形边框，外框表示混凝土池壁（`#B0BEC5` 填充），内框表示有效水深（低饱和灰蓝水体 `#CFD8DC`）；
- **标高标尺**：池壁外侧附带垂直标高标尺（刻度线以米 `m` 为单位，如 `0.00m`、`2.50m`、`5.00m 溢流`），直观反馈防干抽与溢流风险。

### 3.2 潜污泵 / 回流泵标准图元
- 符号为带进出水切向角的圆环：
  - 中控运行反馈：圆内亮绿 `#00C853`；
  - 停止备用：圆内中性灰 `#78909C`；
  - 过载故障：圆内红闪 `#D32F2F`。

### 3.3 离心式罗茨鼓风机
- 符号采用双圆内啮合或蜗壳切向送风图元，标注出风压力（kPa）与实时频率（Hz）。

### 3.4 隔膜计量加药泵
- 采用双单向阀与偏心冲程隔膜图元，标注额定冲程开度（%）与瞬时加药流量（L/h）。

### 3.5 在线水质仪表气泡 (Instrument Bubble)
- 遵循 ISA-5.1 规范，采用上圆下方或标准双线仪表标牌：
  - 上部圆圈标出测点位号：如 `AIT-201`（水质分析）、`FIT-202`（流量）、`LIT-203`（液位）；
  - 下方紧贴白色立体下凹 I/O 域：展示实时测量值与法定工程单位（如 `2.20 mg/L`）。
