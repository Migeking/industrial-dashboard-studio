# 中国工业现场就地控制屏中文术语与信号规范

## 1. 适用范围与设计原则

本规范适用于各类单体工业设备、成套橇装单元或就地电气控制箱（Local Control Panel, 简称 LCP / 现场操作箱 / 现场触摸屏 HMI）。

### 核心准则
1. **纯正规范中文**：严格遵循中国国家标准及行业规范（GB/T 14048、DL/T 5136、HG/T 20507、GB 50055），杜绝生硬英文缩写或中英拼凑（如坚决杜绝“就地 LOCAL”、“远程 REMOTE”等不规范表达）。
2. **权责边界分明**：界面必须一眼明确当前“控制权在何处”、“本画面是否允许动作”、“停机原因与闭锁条件”。
3. **真实诚实表达**：在无现场硬件点表接入时，明确标识“离线演示”或“未接现场信号”，不得将模拟数据包装为现场回读。

## 2. 模式与控制权限标准术语对照

| 标准中文术语 | 英文对照参考 | 现场含义与权限行为 |
|---|---|---|
| **就地控制** | Local Control | 设备控制权由现场就地箱接管，中控/远程下发指令被电气或软件闭锁。 |
| **远方受控** | Remote Control | 设备控制权交由 DCS/PLC/中控上位机，就地启动/停止按钮默认切除（实体急停除外）。 |
| **就地手动** | Local Manual | 现场操作员在就地箱人工点按启动、停止或微调变频器频率。 |
| **远方自动** | Remote Auto | 按照主流程 PID 闭锁、液位联锁或上位工艺逻辑全自动启停调速。 |
| **检修切除 / 停止** | Maintenance / Off | 转换开关置于中间停止位，就地与远方回路均断开，用于检修挂牌。 |
| **就地权限有效** | Local Authority Active | 状态栏高亮提示：操作员可在本屏点击就地操作指令。 |
| **远方闭锁** | Remote Interlocked | 状态栏低对比提示：本地操作禁用，防止现场与中控抢夺控制权产生误动。 |

## 3. 操作指令与动作标准术语

1. **就地启动**（绿色带灯按键）：
   - 触发就地模式下的设备运转流程；若存在联锁未满足或故障未复位，处于禁用（Disabled）状态并提示原因。
2. **就地停止**（红色带灯按键）：
   - 触发就地模式下的受控停机，设备按预设减速斜坡停车。
3. **故障复位**（蓝色/灰色按键）：
   - 在设备故障跳闸后，操作员在现场排查隐患后手动解除报警锁存；复位后设备必须**保持停机备妥**，严禁复位后直接自启动。
4. **紧急停机 / 实体急停**（红色蘑菇头）：
   - 现场物理急停通过硬接线断开接触器或安全继电器电源；画面急停按钮仅为演示或辅助切断，必须声明“不可替代现场实体急停硬件”。
5. **频率给定 / 步进微调**（变频器操作）：
   - 采用“`[ -1.0 Hz ]`”与“`[ +1.0 Hz ]`”等明确步进值；设定值修改后需经过操作员确认下发。

## 4. 状态监测与电气信号标准术语

### 4.1 运行状态
- **运行指示**：绿色指示灯（或按国际标准绿合红分），设备处于正常运转状态。
- **停止备妥**：灰白/灰色指示灯，设备无故障且允许启动。
- **故障锁存**：红色常亮或闪烁，热继电器跳闸、变频器过流或联锁触发，必须人工介入。
- **未接入 / 离线演示**：灰色，明确提示当前为脱机状态，无真实 PLC 信号。

### 4.2 遥测电参与工艺量
- **设定频率**（`SP`）：操作员预设或 DCS 远方给定的目标运行频率，单位 `Hz`。
- **运行频率**（`PV`）：变频器输出端回读的实际电机运行频率，单位 `Hz`。
- **输出电流**：驱动回路三相电流，分别标出 `A相电流`、`B相电流`、`C相电流`，单位 `A`。
- **排气压力 / 出口压力**：鼓风机或泵组出口传感器压力，单位 `kPa` 或 `MPa`。
- **轴承温升 / 轴承温度**：驱动端（DE）与非驱动端（NDE）温度，单位 `℃`。
- **振动烈度**：轴承高频振动加速度或速度有效值，单位 `mm/s`。

## 5. 安全合规提示与防误操作口令

界面底部或安全提示区必须具备以下标准化工业告示文案：
- **急停免责**：“实体急停与电气硬回路保护由现场硬件执行；本画面不提供任何安全旁路功能。”
- **无信号声明**：“离线演示 · 未接入现场 PLC/DCS 信号 · 操作仅改变画面演示状态。”
- **联锁互锁提示**：“远程模式下就地启动指令自动闭锁，需现场转换开关切入就地。”
