# 单设备就地控制屏高水准工业美学与微质感规范

## 1. 核心设计哲学：“单体设备亦有大器工业质感”

单体设备就地操作箱（LCP / 现场触摸屏 HMI）不是简陋的原型线框，更不能做成轻量网页卡片。工业现场的触控屏代表着**安全、稳定、精工与现代工业力量感**。
哪怕屏幕中只有一台鼓风机、一台离心泵或一个阀门单元，画面也必须让现场巡检人员与业主感受到高端工业装备的科技感与信赖感（“WOW at first glance”）。

---

## 2. 机柜与面板质感系统 (Industrial Casing & Chassis)

### 2.1 工业深色微拉丝冷轧钣金（Dark Steel Chassis）
- 界面避免使用轻飘飘的纯白或大面积扁平浅灰。推荐使用深色工业机柜材质（炭黑钢、深钛蓝、防爆铸铝灰），呈现沉稳耐脏的工控气质：
  ```css
  :root {
    --chassis-bg: #0d141d;
    --panel-surface: #131c26;
    --panel-inset: #090e14;
    --metal-line: #223244;
    --metal-highlight: rgba(255, 255, 255, 0.08);
    --screw-head: #3a4b5d;
    --screen-glow: rgba(54, 194, 255, 0.05);
  }
  ```
- **内高光与倒角**：面板四周具备 `1px` 微弱内高光（`box-shadow: inset 0 1px 0 rgba(255,255,255,0.08)`）与沉降阴影（`box-shadow: 0 4px 18px rgba(0,0,0,0.4)`），还原真实机柜嵌入式装配质感。
- **工业沉头螺栓与机械铭牌**：面板四角可点缀高精度的六角/十字沉头防锈螺栓矢量细节，顶部居中配有工业设备激光蚀刻金属铭牌（包含位号、防爆等级 Ex d IIB T4 Gb、防护等级 IP65）。

## 3. 拟真工业元器件设计 (Skeuomorphic Micro-Texture)

### 3.1 三位万能转换开关 (3-Position Selector Switch)
- **手柄造型**：呈现凸起的黑色工业电木或压铸铝旋转手柄，带有中央高光倒角与指槽防滑凹纹。
- **档位刻度**：具有明确的角度旋转状态（如 `-45° 就地`、`0° 停止/检修`、`+45° 远方`），手柄随状态平滑旋转（0.18s 弹性阻尼过渡）。
- **当前激活指示**：档位文字在选通时伴随高对比度微光高亮。

### 3.2 3D 立体带灯操作按键 (Illuminated Push Buttons)
- **物理结构**：外圈具备带倒角的电镀金属保护环（Prevent Accidental Press 物理防误碰圈），内圈为透光亚克力蘑菇面。
- **三种经典工业色温**：
  - **就地启动**：金属环内嵌深邃草绿（`#1f8a53`），按下时呈现高亮翠绿（`#2ee086`）与向内凹陷 `inset` 阴影。
  - **就地停止**：下凹式物理平头按钮，哑光深红（`#962b2b`），停机时常亮或带警告微光。
  - **故障复位**：防误触深工业蓝（`#1b5b88`），故障发生时伴有缓慢呼吸警示。

### 3.3 物理安全急停蘑菇头 (E-STOP Mushroom Button)
- **黄色警戒底座**：明黄色（`#e6a100`）高识别度圆形底座，标有醒目的安全锁闭警示。
- **大红色蘑菇头**：立体鲜红大受力面，印有工业标准的“顺时针旋转释放（◄ TURN TO RESET 旋钮复位）”引导箭头与立体高光弧面。

### 3.4 工业三色声光报警灯塔 (Signal Tower)
- 在面板明显区域或设备旁边配备立式三色警示灯（红/黄/绿）：
  - 红色：故障/跳闸锁存；
  - 黄色：待机/预警/检修；
  - 绿色：正常平稳运转。

## 4. 单设备机械剖面与流态可视化 (Equipment Visualization)

哪怕是一个单一设备，也坚决拒绝粗劣单线条！必须展示其精密的机械工程内核：

1. **结构剖面与材质分层**：
   - 驱动电机部分：精致刻画电机散热鳍片、接线盒、轴端平衡风扇、地脚螺栓减震垫；
   - 传动与轴承部分：刻画主轴联轴器、前后轴承座，并以微缩角标直观标注 **DE（驱动端）/ NDE（非驱动端）温振探头**；
   - 流体机械核心（以鼓风机/泵为例）：剖切出进气导叶、多级钛合金叶轮、渐扩形排气蜗壳；
2. **气动/水力流线粒子动效**：
   - 停机时：管道流线静止，叶轮锁定；
   - 运转时：进气消音器吸入微粒子，沿渐缩管高速汇入，动叶轮产生高速气动透视旋转（结合 `transform-box: view-box`），出风口呈现脉动高亮气压流线；
   - 故障时：流线中断并转为警告暗红/黄，轴承测点闪烁故障热点。

## 5. 变频器数显与电气测量单元 (Digital Instrument Cluster)

- **数显质感**：采用等宽高对比度荧光青（`#36c2ff` 或 `#2de2a6`）段码/点阵发光字体，启用 `font-variant-numeric: tabular-nums`；
- **核心遥测三联阵列**：
  - 设定频率（SP）与实际反馈频率（PV）并列呈现；
  - 三相电流（Ia、Ib、Ic）对称柱状或数字表盘，偏差平衡度直观可视；
  - 排气压力/扬程、电机绕组温度数显；
- **点动微调微操区**：
  - 提供 `[-1.0 Hz]`、`[-0.1 Hz]`、`[+0.1 Hz]`、`[+1.0 Hz]` 触控按键，配合设定值下发确认机制。

## 6. 工控触屏多分辨率与 Scale 响应式原则

1. **基准画布**：1920×1080 原生高清，元素饱满不空旷；
2. **紧凑工控屏模式**：1024×768 常见工控一体机触屏，通过栅格重排保证按键最小触控高度不低于 `48px`，防止现场戴手套误触；
3. **Scale 缩放算法**：采用平滑的等比居中无黑边缩放，确保任意宽屏、窄屏和全屏切换时无模糊与位移。
