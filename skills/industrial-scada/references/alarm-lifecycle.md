# 工业告警生命周期规范 (Alarm Lifecycle)

根据国际标准 ANSI/ISA-18.2 及国家标准 GB/T 41261《过程工业报警系统管理》，SCADA 界面中的告警不仅是文本展示，更是一套严密的状态机。

---

## 一、告警状态机流转

所有过程告警与设备跳闸必须严格遵循以下四态闭环模型：

```
                ┌──────────────── 发生越限 ────────────────┐
                │                                          │
                ▼                                          │
    [ 未确认报警 UNACK ] ──(操作员确认 Ack)──> [ 已确认报警 ACKED ]
    (红色闪烁 + 蜂鸣)                           (红色常亮，蜂鸣停)
                │                                          │
          (工艺恢复正常)                             (工艺恢复正常)
                ▼                                          ▼
    [ 恢复未确认 RTN_UNACK ]                    [ 正常状态 NORMAL ]
    (绿色闪烁，提示曾发生)                                 │
                │                                          │
          (操作员确认 Ack)                                 │
                └──────────────────────────────────────────┘
```

---

## 二、告警优先级与视觉映射

| 级别 | 视觉颜色 | 闪烁频率 | 蜂鸣特征 | 适用场景 |
|---|---|---|---|---|
| **紧急 (Emergency)** | `--danger` (`#ff5d5d`) | 快速闪烁 (1.0s) | 连续急促高音 | HH 超高液位、LL 防干转切断、火灾急停 |
| **高危 (High)** | `--warning` (`#ffb547`) | 慢速呼吸 (1.8s) | 间歇蜂鸣 | 单泵过载跳闸、通信中断、出水压力过高 |
| **预警 (Low)** | `--accent` (`#36c2ff`) | 常亮无闪 | 提示单音 | 达到增泵阈值、轴承温度偏高、维保到期 |

## 三、SCADA 界面常驻报警条规范 (Alarm Banner)

1. **常驻顶部**：SCADA 顶栏下方固定一行 36px 的 Alarm Banner，显示当前**最高优先级、最新发生的未确认告警**。
2. **消音 (Silence) 机制**：
   - 告警发生时蜂鸣器鸣叫；
   - 操作员点击【消音】按钮后，声音立即停止，但界面**红闪状态保持不变**，确保视觉警示不被忽略。
3. **确认 (Acknowledge) 机制**：
   - 支持【单条确认】与【全部确认】；
   - 点击确认后，告警从“未确认红闪”转为“已确认红常亮”；
   - 确认动作必须在 Audit Trail 审计日志中记录：操作工号、确认时间。
4. **死区与延时防抖**：
   - 液位在阈值边缘小幅度波动时，采用 $\pm 0.05m$ 迟滞死区与 $3s$ 持续时间滤波，避免出现高频告警泛滥（Alarm Chattering）。
